# Motion Video Director — demo film

A 26-second, 1080×1920 motion-graphics film made with the
[Motion Video Director skill](https://github.com/Miftahul-Islam-Efaz/Motion-graphics-skill) (v3.5.2).
Every frame and every sound is generated by code in this folder: no footage,
no stock, no templates, no audio samples.

**Watch:** `renders/final/Motion Video Director - Demo v1.mp4` (H.264 + AAC, 3.5 MB)
**Quick look:** `demo-preview.gif`

| | |
|---|---|
| Format | 9:16 · 1080×1920 · 30 fps · 780 frames · 26.00 s |
| Picture | Canvas (Skia) via `@napi-rs/canvas` → raw RGBA → FFmpeg libx264, crf 18 |
| Sound | 40 procedural cues synthesised with NumPy, stereo, two-pass `loudnorm` |
| Loudness | −14.5 LUFS integrated · true peak −1.5 dBTP |
| Determinism | every frame is `f(t)`; re-renders are byte-identical |

## Structure

| Time | Scene | Beat |
|---|---|---|
| 0–3 s | `hook` | "26 seconds" + a render that finishes inside the hook |
| 3–7 s | `notimeline` | the old way: no timeline, no keyframes — just `draw(f/30)` |
| 7–12 s | `math` | every frame is math: the ease-out-cubic curve, drawn live |
| 12–18 s | `triptych` | type / motion / sound, plus the cue sheet that drives them |
| 18–22 s | `pipeline` | brief → boards → code → mix, one command |
| 22–26 s | `endcard` | skill lockup, repo link, scene strip |

## How it is built

```
src/data.js        canvas size, palette, fonts, scene ranges (the timing source)
src/timing.js      cut points + the 40 sound cues
src/draw.js        easing, type helpers, HUD, footer, grain, vignette, transitions
src/scenes/*.js    one pure draw(ctx, t) per scene
src/render.mjs     stills · contact sheets · MP4 (pipes frames to FFmpeg)
scripts/sound.py   synthesises every cue from plan/beats.json, mixes and normalises
scripts/export-beats.mjs  writes plan/beats.json from src/timing.js
```

## Re-render it

```bash
npm install                       # @napi-rs/canvas only
node scripts/export-beats.mjs     # timing → plan/beats.json
python3 scripts/sound.py          # needs numpy + ffmpeg on PATH
node src/render.mjs --from 0 --to 26 --fps 30 --scale 1 \
     --out renders/final --name "Motion Video Director - Demo v1" --audio assets/mix.wav
```

Preview loop used while building (dense contact sheets, low resolution):

```bash
node src/render.mjs --sheet --from 3 --to 7 --fps 8 --scale 0.28 --out cache/sheets --name oldway
node src/render.mjs --stills 2.5,9.75,17.25 --out cache/stills --scale 0.5
```

## Design notes

The look is a render console: ink `#0A0C0F`, cream `#F2EEE4`, one lime accent
`#C7FF3E` and ember `#FF5A2A` used sparingly. Space Grotesk carries the display
type, Inter the body, JetBrains Mono every instrument label. Full rules live in
[`TASTE.md`](TASTE.md); the visual spec is repeated there in concrete values.
