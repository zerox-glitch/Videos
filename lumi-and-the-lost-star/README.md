# Lumi & the Lost Star

A 72-second wordless storybook cartoon for little kids, made with the
[Motion Video Director skill](https://github.com/Miftahul-Islam-Efaz/Motion-graphics-skill).

A tiny firefly named Lumi finds a star that has fallen out of the sky. It is far too heavy
for one little bug — so she calls her friends, and together they carry it back up past the clouds.

**Watch:** `renders/final/Lumi and the Lost Star v2.mp4`
**Quick look:** `demo-preview.gif` · **Poster:** `poster.jpg`

| | |
|---|---|
| Format | 1920×1080 · 24 fps · 1728 frames · 1:12 |
| Picture | Canvas (Skia) → FFmpeg H.264, crf 18, yuv420p |
| Sound | 24-bar music-box score at 80 BPM + 45 designed cues + ambience, all synthesised locally |
| Loudness | −13.9 LUFS integrated · true peak −1.8 dBTP |
| Language | wordless, with gentle on-screen captions |
| Audience | ages 3–7 |

## The story

| Time | Beat |
|---|---|
| 0:00 | A quiet meadow under a silver moon. Lumi loops past the big tree to say hello. |
| 0:12 | A star slips out of the sky and lands with a bump. |
| 0:24 | Too heavy for one bug — two tries, two falls, then an idea. |
| 0:36 | Friends arrive one by one; together they lift it past the clouds. |
| 0:48 | Released, the star bursts into light and draws a heart across the sky. |
| 1:00 | Lumi flies home to her mushroom, yawns, and the title card says goodnight. |

## Structure

```
src/data.js          canvas, palette, fonts, scene ranges
src/timing.js        captions, dissolves, cue sheet, music arrangement
src/draw.js          easing, type, glows, sparkles, dust, captions, film finish
src/world.js         sky, stars, moon, hills, grass, clouds, fireflies, camera
src/characters.js    Lumi, the star, her friends, constellation, trails
src/scenes/*.js      one pure draw(ctx, t) per act
src/render.mjs       stills · contact sheets · MP4
scripts/sound.py     music + foley synthesis, mix and loudness mastering
scripts/export-beats.mjs  writes plan/beats.json (shared by picture and sound)
```

## Re-render

```bash
npm install
node scripts/export-beats.mjs
python3 scripts/sound.py
node src/render.mjs --from 0 --to 72 --fps 24 --scale 1 \
     --out renders/final --name "Lumi and the Lost Star v2" --audio assets/mix.wav
```

Preview loop:

```bash
node src/render.mjs --sheet --from 24 --to 36 --fps 3 --scale 0.24 --out cache/sheets --name heavy
node src/render.mjs --stills 13.9,27.4,44.5 --out cache/stills --scale 0.5
```
